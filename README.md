## 🛠️ Technology Stack

- **Framework**: React 18 & TypeScript (Strict Mode)
- **Routing**: `react-router-dom` with smooth scroll restoration & error boundaries
- **3D & WebGL**: `three.js` (`@types/three`)
- **Animation & Physics**: `framer-motion` (Spring physics & hardware-accelerated transforms)
- **Styling**: Tailwind CSS & Glassmorphism design tokens
- **Icons**: `lucide-react`
- **Build Tool**: Vite 6 (Fast HMR & Rollup code-splitting)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build & Verification
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory with code splitting.

### 4. Preview Production Build
```bash
npm run preview
```

## 🌐 Production Deployment

### Hostinger (Static / Git Deployment)
1. Build Directory: `dist`
2. Build Command: `npm run build`
3. Node Version: 18.x or 20.x
4. SPA Routing: Handled automatically by `public/.htaccess`.

### Vercel / Netlify / Cloudflare
- Handled out of the box via `vercel.json` and `public/_redirects`.
